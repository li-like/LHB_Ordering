# 图标资源说明

此目录用于存放微信小程序的图标资源，需要准备以下PNG格式的图标文件：

## TabBar图标 (40x40px, 建议使用80x80px以支持高分辨率)

1. **home.png** - 首页图标（未选中状态）
2. **home-active.png** - 首页图标（选中状态）
3. **family.png** - 家庭图标（未选中状态）
4. **family-active.png** - 家庭图标（选中状态）
5. **profile.png** - 个人中心图标（未选中状态）
6. **profile-active.png** - 个人中心图标（选中状态）

## 其他图标

7. **wechat-icon.png** - 微信登录图标
8. **default-avatar.png** - 默认头像
9. **logo.png** - 应用logo

## 设计要求

- 所有图标建议使用PNG格式
- TabBar图标建议大小：81x81px（微信小程序官方推荐）
- 图标风格保持一致
- 选中状态图标使用主题色：#FF6B95
- 未选中状态图标使用灰色：#C0C4CC

## 快速制作图标

可以使用以下工具制作图标：
- 阿里巴巴矢量图标库 (iconfont.cn)
- 字节跳动IconPark (iconpark.oceanengine.com)
- Figma 或 Sketch
- Canva 等在线设计工具

制作完成后，请将PNG文件放置在对应目录中替换占位符文件。
