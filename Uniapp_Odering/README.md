# 家庭点餐小程序

## 项目简介

一个基于uni-app开发的家庭内部微信点餐小程序，旨在为家庭成员提供便捷的点餐服务，支持饮食偏好记录、智能推荐等功能。

## 功能特色

### 已完成功能

✅ **用户登录与认证**
- 支持微信一键登录
- 自动保存用户信息
- 登录状态检查

✅ **家庭成员管理**
- 创建和管理家庭
- 添加/移除家庭成员
- 成员角色管理（管理员/普通成员）
- 邀请码分享功能

✅ **可爱简洁的UI设计**
- 粉色系温馨主题
- 响应式布局
- 平滑动画效果
- 直观的用户界面

### 计划开发功能

🔄 **饮食规律记录**
- 记录家庭成员饮食偏好
- 统计分析喜好数据
- 生成个性化推荐

🔄 **"随便"按钮智能推荐**
- 基于偏好的自动推荐
- 多维度筛选（主食、荤素、口味等）
- 随机推荐算法

🔄 **菜谱管理系统**
- 支持图片上传
- 详细的制作步骤
- 收藏和分享功能
- 个人菜谱库

🔄 **用餐时间提醒**
- 自定义用餐时间
- 智能推送通知
- 家庭用餐日历

## 技术架构

- **框架**: uni-app (Vue 3)
- **UI设计**: 自定义组件 + 原生样式
- **数据存储**: uni.storage (本地存储)
- **小程序平台**: 微信小程序
- **开发语言**: JavaScript/Vue.js

## 数据结构

### 用户信息 (userInfo)
```javascript
{
  nickName: "用户昵称",
  avatarUrl: "头像地址",
  openid: "用户唯一标识",
  loginTime: 时间戳
}
```

### 家庭数据 (familyData)
```javascript
{
  familyId: "家庭唯一标识",
  familyName: "家庭名称",
  members: [
    {
      id: "成员ID",
      name: "成员姓名",
      avatar: "头像地址",
      role: "admin|member",
      joinTime: 时间戳,
      preferences: {
        taste: [],      // 口味偏好
        allergies: [],  // 过敏信息
        dislikes: []    // 不喜欢的食物
      }
    }
  ],
  createTime: 时间戳
}
```

## 安装和运行

1. **环境准备**
   - 安装 Node.js
   - 安装 HBuilderX 或 VSCode
   - 配置微信开发者工具

2. **项目启动**
   ```bash
   # 安装依赖（如果有）
   npm install
   
   # 在HBuilderX中打开项目
   # 运行 -> 运行到小程序模拟器 -> 微信开发者工具
   ```

3. **开发调试**
   - 在微信开发者工具中预览
   - 支持热重载开发
   - 可以使用模拟登录测试功能

✅ **组件规范**

✅ **配置文件**

### 开发部署流程

1. **开发环境**
   ```bash
   # 在HBuilderX中打开项目
   # 运行 -> 运行到小程序模拟器 -> 微信开发者工具
   ```

2. **微信开发者工具配置**
   - 新建小程序项目
   - 选择本项目的unpackage/dist/build/mp-weixin目录

3. **必需的配置**
   - 在manifest.json中配置正确的AppID
   - 准备所需的图标资源（见static/ICON_README.md）
   - 配置服务器域名（如需网络请求）
